# Frozen multi-timeframe baseline

Recorded: 2026-08-13

This is a research-only snapshot of the first corrected multi-timeframe replay.
It does not change application behaviour or authorize testnet or live trading.

## Frozen rule subset

- Three-day green momentum context with day-three resistance.
- At least three daily resistance reactions.
- First confirmed rejection-and-swing-low break on 1m, 3m, 5m, or 15m.
- First structural support counted as the initial take-profit reference.

## Result

| Measure | Result |
| --- | ---: |
| Default-like matching entries | 6 |
| Entries reaching first support | 4 |
| Preliminary first-target win rate | 66.7% |
| Earlier sub-period | 2 wins / 3 entries |
| Later sub-period | 2 wins / 3 entries |

## Interpretation

The sample is retained as a comparison baseline for later, larger replays. Six
entries are not enough to validate a 60% strategy or to make a profitability
claim. Later studies must use separately dated data and report their result
alongside this snapshot rather than replacing it.
